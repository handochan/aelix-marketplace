Extensions for aelix

aelix is an auditable, self-hostable, signed terminal coding agent.

This is the community catalog of extensions you can install into aelix. The catalog only decides what to install — every install still goes through aelix's own consent prompt, integrity pin, and signature checks on your machine.

  • Auditable
  • Self-hostable
  • Signed releases
  • Runs in your terminal
  • Works air-gapped
Install aelix 
curl -fsSL https://raw.githubusercontent.com/handochan/aelix-ai/main/install.sh | sh

Review the script before piping it to a shell — that is the honest way to run any curl | sh installer. The aelix source lives at github.com/handochan/aelix-ai.

About the sha256 chip: the hash shown on a card is a display-only advisory value copied from the catalog entry.
